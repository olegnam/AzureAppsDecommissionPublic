# Contributing

Contributions are welcome, but this repository handles Azure resource deletion and should be treated as a high-risk operational tool.

## Before contributing

- Read `SECURITY.md`
- Keep examples sanitized and non-production
- Do not include real resource names, Azure IDs, or credentials
- Do not add sensitive local files or generated output

## Pull request guidance

- Keep changes small and targeted
- Preserve dry-run-first behavior
- Document any new parameters in `README.md`
- Add explicit warnings if a change increases operational risk

## Code of conduct

Please be respectful and careful when proposing changes to scripts that affect Azure infrastructure.
